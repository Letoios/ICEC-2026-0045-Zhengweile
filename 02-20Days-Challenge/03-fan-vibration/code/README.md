# 项目三 代码说明

---

## 关于 tools/ 与 _*.py

`code/` 根下 35 个 `.py` 是**正式脚本**：特征提取、分类、分层判定、振动、开集、画图、自检，都能直接跑。

`code/tools/` 里 2 个是**生成器**，用来产出必交的过程材料，保留是因为评委可能问「日志怎么来的」：

| 文件 | 产出什么 |
|---|---|
| `tools/_gen_logs.py` | `process_logs/*.md` 里的逐日记录骨架（内容仍要手写，脚本只保证日期与条目结构一致） |
| `tools/_gen_ps1.py` | 入库脚本 `入库_项目三.ps1` |

此外还有约 48 个 `_*.py`（`_fix_fig08b.py`、`_patch_readme5.py` 之类），是开发过程中「用一段 Python 去改另一个文件」的临时补丁，跑完即废，**没有入库**——它们不参与任何结论的复现，留着只会让 `code/` 里分不清哪几个是真的。
