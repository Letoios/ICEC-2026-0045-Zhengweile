## 二、五分类为什么上不去（不是没调好）

### 事实

| 口径 | 五分类 | 三分类 |
|---|---|---|
| 留一法 | 68.4% | 90.8% |
| **分组交叉验证** | **61.2%** | **90.8%** |

五分类的错误集中在 C1/C2/C3 之间（一档/三档/五档）：

```
           预测 C1  C2  C3  C4  C5
真值 C1      14    3   6   0   0
真值 C2       5    9   3   2   0
真值 C3       6    6  10   1   0
真值 C4       3    0   3  10   0
真值 C5       0    0   0   0  17
```

C4（贴胶带）和 C5（半遮挡）基本全对，错的都是档位。

### 归因

三档实测转速差只有 **20% 左右**（一档 33.7 Hz → 三档 37.0 → 五档 40.3 Hz），而同一档位换个录音距离，谱心能差 **50% 以上**（组内 372–1366 Hz）。

**信号里「位置」这一维的方差大于「档位」这一维。** 分类器看到的最近邻，往往是同一个位置录的另一档，而不是同一档在别的位置录的。

### 结论

这不是分类器的问题，是**录音条件没控住**。要修必须重采：每次开机先录 5 秒基准段，用 `谱心(待测)/谱心(基准)` 抵消位置偏差。现有 98 段没有基准段，修不了。

**关键结论：三分类在 5 dB 信噪比下仍然稳健，五分类从头到尾都在 60% 附近晃——加噪并没有让它更差。**

## 四、盲测 3/5 怎么解释

五段盲测（b1–b5）只对 3 段。查下来**五段的谱心是 1187–1709**，而训练集 98 段的谱心是 386–1935（中位 916）。

五段全落在训练集的上半区——说明那批录音是**另一次录音条件**（手机离风扇更近、房间更亮），属于分布外样本。

**这不是「模型坏了」，是「模型没见过这个位置」。** 分组交叉验证的 61.2% / 90.8% 才是它在本分布内的真实水平。

答辩时必须主动说这句，否则「91.6%」和「60%」两个数字摆在一起没法解释。

## 五、没有独立测试集

98 段全部参与过特征选择和参数调整（选 6 个特征、定 k=3 都是看着这 98 段定的）。所以严格说，**没有一段是「模型从没见过」的数据**。

缓解措施：
1. 主口径用分组 CV（留出整批），比留一法严格；
2. 盲测那 5 段录于训练之后，虽被证明是分布外样本，但至少是「未来数据」；
3. 答辩时明确说：「这是一个 98 段的探索性数据集，泛化能力需要用新数据验证。」

## 六、两个负结果（证明走不通，避免后人重复）

### 1. 多窗口投票 —— 更差

把每段切成 3 s 窗（步长 1.5 s），逐窗分类再投票：

| | 五分类 | 三分类 |
|---|---|---|
| 单窗（整段） | 66.3% | 90.8% |
| 多窗投票 | 58.2% | 82.7% |

原因：3 s 窗的频率分辨率只有 0.33 Hz/bin，f0 估不准；投票把估计噪声放大了。

### 2. 谱白化 —— 五类微降、三类下降

用滑动中值谱做分母再提特征：五类 62.1%、三类 85.3%，都没超过原方法。

原因：白化抹掉了低频「呼呼」声的绝对强度，而这正是区分「正常」与「遮挡」的主要线索。

## 七、还剩下的弱项（改不动的）

| 弱项 | 为什么改不动 |
|---|---|
| 只有一台手机、一个风扇 | 设备与器材限制 |
| 段长 10–26 s 不统一 | 手机录音机自动分段 |
| 没有频谱仪的绝对声级 | 手机麦克风未标定 |
| 没有真实故障（胶带/纸板是模拟） | 手头没有坏的风扇 |

这四条写进报告的「局限」一节，不藏。
