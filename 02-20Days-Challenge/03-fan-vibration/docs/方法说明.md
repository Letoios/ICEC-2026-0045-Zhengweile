# 方法说明

## 1 整体流程

```
mp3/wav ──解码──> 48 kHz 单声道 PCM
   │
   ├─ 裁掉首尾 0.3 s
   ├─ 平均功率谱（频谱 16384 点 / 基频 65536 点，Hann 窗）
   │
   ├─ 时域：RMS、波峰因数、偏度、峰度
   ├─ 频域：谱心、低频/中频/高频能量占比
   ├─ 谐波：HPS 估基频 f0，再取 h2/h3/h4 相对幅度
   │
   └─> 6 维特征（经贪心选择）──标准化──> kNN(k=3) ──> 类别
```

## 2 特征怎么来的、为什么只剩 6 个

### 2.1 原始 8 个

| 特征 | 含义 |
|---|---|
| `f0` | 基频（HPS 谐波乘积谱） |
| `centroid` | 谱心 |
| `e_low` / `e_mid` / `e_high` | <500 / 500–2000 / >2000 Hz 能量占比 |
| `h2` / `h3` / `h4` | 第 2/3/4 谐波相对基频的幅度 |

### 2.2 全部与「音量」解耦

同一台风扇，手机往前挪 10 cm，声压级能差 6 dB。如果特征里带绝对能量，分类器学到的就是「录音距离」而不是「工况」。所以：

- 能量类**全部除以本段总能量**，变成占比；
- `h2/h3/h4` 是**比值**，分子分母同比例缩放，天然抵消；
- `f0` 是频率，与距离无关。

### 2.3 贪心选择：8 → 6

逐个去掉看准确率变化（98 段，kNN k=3）：

| 去掉 | 五类 | 三类 |
|---|---|---|
| —（全 8 个） | 66.3 % | 90.8 % |
| **`f0`** | **58.2 %** | 86.7 % | ← 掉最多，最关键 |
| `h3` | 62.2 % | 89.8 % |
| `h4` | 65.3 % | 90.8 % |
| `h2` | 66.3 % | 90.8 % |
| **`centroid`** | **67.3 %** | 90.8 % | ← 去掉反而涨 |
| **`e_low`** | **67.3 %** | 89.8 % | ← 去掉反而涨 |
| `e_high` | 67.3 % | 92.9 % | ← 去掉三类涨 |

**`centroid` 和 `e_low` 是「位置特征」而不是「工况特征」**——它们直接反映手机离风扇多远、朝哪个角度，带进来只会干扰。去掉它们后，五类 66.3 → 68.4。

最终保留：**`f0`、`e_mid`、`e_high`、`h2`、`h3`、`h4`**。

### 2.4 为什么要 `h2/h3/h4`

只看谱心，只能区分「亮/闷」。但**失衡**与**遮挡**恰恰都不改变基频，改的是谐波结构：

- 扇叶贴胶带 → 每转一圈多一次额外气流扰动 → 边带增强、谐波比变化；
- 挡住进风口 → 风量掉一大截，叶片负载变轻、转速上升，同时气流挤过半边的缝隙产生**稳定哨音**（C5 的 f0 从约 40 Hz 跳到 91.6 Hz，h2 高达 8.83）。

这两类差异在「谐波相对幅度」上比在「谱心」上清楚得多。

## 3 分类器为什么用 kNN

样本只有 98 段，五类里最少的 16 段。这种规模下：

- 训练深度模型 = 过拟合；
- 逻辑回归/线性判别 = 假设各类协方差相同，而这里 C5 的方差明显更小；
- **kNN 不需要训练**，且能直接给出「离哪个已知样本最近」的解释。

`k=3` 是试出来的：k=1 太敏感，k=5 会把 C2/C3 这种相邻类糊在一起。

## 4 为什么档位分不开（关键）

### 4.1 现象

| 工况 | f0 中位 | 谱心中位 |
|---|---|---|
| C1 一档 | 33.7 Hz | 686 Hz |
| C2 三档 | 37.0 Hz | 756 Hz |
| C3 五档 | 40.3 Hz | 717 Hz |

一档到五档，基频只从 33.7 走到 40.3 Hz（+20 %），而**同一档位内部的谱心跨度是 372–1366 Hz（3.7 倍）**。

组内差异比组间差异大一个数量级 → 任何分类器都分不开。

### 4.2 原因

风扇转速与档位不是线性关系，而且**手机录音位置在整个采集过程中并不固定**。距离变化会同时改变：

1. 高频衰减（空气吸收）→ 谱心大幅平移；
2. 指向性（麦克风不是全指向）→ 谐波比漂移。

这两项的幅度都远超「一档 vs 五档」的真实差异。

### 4.3 这不是特征没选好——四种做法都试过

| 做法 | 五分类准确率 |
|---|---|
| 只用谱心 + 能量占比 | 43.2 % |
| 加入 f0（HPS 估转速） | 56.8 % |
| 加入 h2/h3/h4 后 kNN | 66.3 % |
| 贪心选择 6 个特征 | **68.4 %（留一法）/ 61.2 %（分组交叉验证）** |

另外两种「看起来该有用」的方法实测**更差**，已作为负结果保留在 `code/winvote.py` 与 `code/white.py`：

| 做法 | 五类 | 三类 | 为什么失败 |
|---|---|---|---|
| 多窗口投票（3 s 窗） | 58.2 % | 82.7 % | 3 s 窗频率分辨率只 0.33 Hz/bin，f0 估不准 |
| 谱白化（中值谱做分母） | 62.1 % | 85.3 % | 抹掉了低频「呼呼」声强度，而这正是判遮挡的主要线索 |

**结论：61.2 %（分组 CV）已经是这套数据的天花板，再调参就是过拟合。**

### 4.4 所以项目这样定位

课题原文写的是「日常旋转机械/**电器异常**声振诊断仪」——要诊断的是「有没有异常」，不是「它在几档」。因此：

- **主结论：三类（正常 / 失衡 / 遮挡）90.8 %**
- **附带结论：五类 61.2 %，并解释为什么档位上不去**

这比硬凑一个 90 % 的五分类要诚实，也更能回答评委的追问。

## 5 评估方法（两种口径都报）

### 5.1 留一法（leave-one-out）

每次留 1 段当测试，其余 97 段训练。缺点：同一批次的其他 4 段仍在训练集里，模型"见过"这个录音环境，**必然偏高**。

### 5.2 分组交叉验证（主口径）

每次留出**一整个批次**（同一次录音里连续的 5 段）。模拟"换一次录音环境"。

| 口径 | 五类 | 三类 |
|---|---|---|
| 留一法（偏高） | 68.4 % | 90.8 % |
| **分组交叉验证（主口径）** | **61.2 %** | **90.8 %** |

**关键观察：三类在两种口径下都是 90.8 %** —— 说明故障判据（谐波结构 + 高频占比）不吃录音位置的影响，这是真本事，不是过拟合。五类则从 68.4 掉到 61.2，掉的正是"位置记忆"那部分。
