# 11-03　立项与环境排查

## 今天要解决什么
选定项目三（手机声学诊断旋转机械），先把「能不能在这台电脑上处理音频」搞清楚。

## 遇到的坑
1. 系统没有 ffmpeg 命令行，`pip install` 各种失败：
   - `ERROR: Could not install packages due to an OSError: [Errno 13] Permission denied: '...pip-unpack-...\*.whl.metadata'`
   - 把 TEMP 改到工作区、加 `--target` 都不行
2. 也没有 scipy / soundfile / librosa。

## 怎么解决的
在 `D:\deepseek\ffmpeg.dll`（Electron 自带的那个）上用 `ctypes` 直接调 libavcodec。
导出符号里有 `avcodec_find_decoder` / `avcodec_open2` / `avcodec_send_packet` / `avcodec_receive_frame`，
但没有 `av_parser_init`，所以 MPEG 帧切分得自己写。
→ 见 `code/mp3read.py`。

## 结论
不装任何第三方包也能解 mp3。后面所有流程都基于 numpy + 标准库。
