## 二、选题说明

阶段一（`01-Field-Discovery/`）做两个课题，都用手机传感器完成，都能从原始数据重算出报告里的每一个数。

### 课题 06：校园昼夜声学噪声地图测绘

**为什么选这个题**：校园里的噪声每天都 "听得见"、却从来没有 "看得见" 的记录——没人说得清早读时的图书馆、午间的食堂、下课的主干道到底吵到什么程度、超没超标。分贝计的读数是瞬时的，噪声地图多半是事后补画的。我想用一部手机把这件事变成一套可复现的流程：**测得清、判得准、看得见**，并且把这套流程连同原始数据一起交出去，别人能重算出同样的数。

**要解决的问题**

第一，15 组读数怎么和不同功能区的限值挂钩，才能不靠事后解释；第二，单次读数本身就有几 dB 的波动，判定会不会因为多采一次就翻转；第三，如果真把超标做成灯，"吵了一下" 和 "一直吵" 怎么区分开——这两种情况的治理办法完全不同。

**测量设计**

- 点位 5 处：图书馆、食堂、主干道、运动场、实训室走廊
- 时段 3 个：早 / 午 / 晚
- 合计 15 组，每组记录等效声级与峰值

**判定依据**

按 GB 3096-2008《声环境质量标准》，各点位归属不同功能区，限值不同：

| 点位 | 功能区 | 昼间限值 | 夜间限值 |
|---|---|---|---|
| 图书馆 | 1 类 | 55 | 45 |
| 食堂 | 2 类 | 60 | 50 |
| 主干道 | 4a 类 | 70 | 55 |
| 运动场 | 2 类 | 60 | 50 |
| 实训室走廊 | 1 类 | 55 | 45 |

单位为 dB(A)。分级不写绝对数，而是以限值 L 为基准取偏移量：L−10 / L / L+5 / L+10 四个断点切成五档（安静 / 达标 / 轻度超标 / 中度超标 / 重度超标），一套规则适配全部点位。

**交付内容**

1. 15 组声学数据表（Excel，含公式判定与条件格式）
2. 三时段「超出量 Δ」雷达图（一张图三条多边形，Δ = 该点位该时段的 Leq − 适用限值；另有 15 格点位×时段热力图）
3. 声学超标自动提醒的光效逻辑设计（分级编码、状态机、时序参数、验收用例）
4. 噪声地图、回放仿真（光效状态机在 15 段实测序列上的逐秒回放）、稳健性与不确定度分析
5. 代码包（`06-noise/code/`）：`recompute.py` 从 `data/` 重算全部指标、`robust.py` / `gum.py` 复算不确定度，**在包内直接可跑**；画图脚本同目录留档，需在作者工作区运行（依赖原始 zip 与中间结果）

> 结果摘要：15 组里 **12 组超标、3 组达标**；判定真正擦线的只有 2 组（S04 运动场早 +1.5、S09 中运动场 +0.8），翻转率 17.5% / 30.2%。其余 13 组的最小 |Δ| 是 2.5 dB（S02），翻转率均 ≤ 5.3%。绝对声级受逐段自动校准限制，只做同机同管线的相对比较——这条在 `docs/不确定度预算.md` 里算过账。

### 课题 08：多姿态步态加速度特征采集与对比

**为什么选这个题**：手机里现成就有加速度计，但 "手机能不能认出你在走、在跑、还是在上下楼" 这件事，很少有人拿自己的数据认真验证过。我想验证：**不装额外设备、不用摄像头，只靠随身一部手机的竖直加速度波形，能不能把几类动作分开，并且说清它在什么情况下会失效。**

**要解决的问题**

不同动作在竖直加速度上留下的波形形状不一样：走路最规整、跑步幅度最大、下楼有触地尖峰。问题在于这些差异能不能被**无量纲**的少数量化——一旦依赖绝对幅度，换个人、换个握法就全乱了。

**测量设计**

- 状态 5 类：静止 / 平地走 / 跑步 / 上台阶 / 下台阶（课题要求 "4 种状态（含上下楼梯）"，这里把上、下拆成两类分别标定，属超要求）
- 采集：Phyphox「Acceleration with g」，480 Hz，单段 ≥ 15 s，手持自然摆臂
- 特征 5 个：竖直 RMS（唯一保留的绝对量）、步频、自相关、正负峰不对称、偏度——除 RMS 外全部无量纲

**判定依据**

六步顺序规则，命中即停：静止 → 信息量拒答 → 跑步 → 下台阶 → 平地走 → 上台阶兜底。阈值取在两类样本实测范围的**空档中点**，不是拟合出来的；最薄的一条余量是下楼判据 `diff`（+0.060 对 +0.035 门槛，余量 0.019），所以另外并了一个偏度条件做双保险。

**结果与边界**

- 整段判定：训练集 **8 / 8**
- 滑窗逐窗（每 1 s 滑一次）：8 s 87.8% / 10 s 90.8% / 12 s **94.5%** / 15 s 98.7% / 20 s 100%；各窗口下多数投票均 8/8
- 扰动：幅度 ×0.5–×2.0、时间伸缩 ×0.85–×1.25、加噪 40–10 dB 下判定均不变
- 失效边界如实记录：端握不动、极慢速行走各只有 **n = 1** 段，观察到失效但不做统计结论；这些写在 `阈值规则.md` 第七节和 `ANOMALIES.md` 里

> 说明：两个课题的 `process_logs/`、`ANOMALIES.md`（异常与取舍记录）、采集证明（设备型号、设备时间与文件 SHA256）都在各自的交付目录里，用来证明数据是本人亲自采集、结论可回溯。
