## 二、选题说明

### 课题 06：校园昼夜声学噪声地图测绘

**为什么选这个题**：（待填写，两三句话说明动机，例如：校园里“哪里吵、什么时候吵”缺少可量化的记录，希望用低成本手段把声环境变成一张可读的地图。）

**要解决的问题**

校园噪声有一个天然矛盾：声音“听得见”，超标“看不见”。分贝计读数是一次性的，噪声地图往往也是事后补画的。本课题要把这件事变成一套可复现的流程——**测清楚、判得准、看得见**。

**测量设计**

- 点位 5 处：图书馆、食堂、主干道、运动场、实训室走廊
- 时段 3 个：早 / 午 / 晚（晚场须安排在 22:00 之后，才能套用夜间限值）
- 合计 15 组，每组记录等效声级 Leq 与峰值 Lmax

**判定依据**

按 GB 3096-2008《声环境质量标准》，各点位归属不同功能区，限值不同：

| 点位 | 功能区 | 昼间限值 | 夜间限值 |
|---|---|---|---|
| 图书馆 | 1 类 | 55 | 45 |
| 食堂 | 2 类 | 60 | 50 |
| 主干道 | 4a 类 | 70 | 55 |
| 运动场 | 2 类 | 60 | 50 |
| 实训室走廊 | 1 类 | 55 | 45 |

单位为 dB(A)。分级不写绝对数，而是以限值 L 为基准取偏移量：L−10 / L / L+5 / L+10 四个断点切成五档（安静 / 达标 / 轻度超标 / 中度超标 / 重度超标），一套规则适配全部点位。

**交付内容**

1. 15 组声学数据表（Excel，含公式判定与条件格式）
2. 昼夜三时段声级雷达图（Leq 与 Lmax 各一张）
3. 声学超标自动提醒的光效逻辑设计（分级编码、状态机、时序参数、验收用例）
