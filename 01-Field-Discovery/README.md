# 阶段一　现场调研

用手机能做的传感器，去测一件真实存在、但平时没人量化的事。

---

## 本阶段做了什么

两个课题，都是先定判据、再采数据、最后自己给自己挑错。

### 课题 06　校园昼夜声学噪声地图测绘

用手机分贝计在图书馆、食堂、主干道、运动场、实训室走廊 5 处点位，测早 / 中 / 晚的噪声，做 15 组数据表、雷达图和噪声地图，再设计一套超标自动提醒的光效逻辑。

| 项 | 内容 |
|---|---|
| 目录 | [`06-noise/`](06-noise/) |
| 数据 | 15 组（5 点位 × 3 时段），每组 82–125 秒原始记录，保留 Phyphox 原始 zip |
| 主结论 | **昼间限值口径下 12 组超标 / 3 组达标**（3 组达标全在主干道，4a 类限值 70 最宽） |
| 一句话 | 夜里"全员超标"是假象——实测声级与白天几乎持平（−3.1 ~ +1.6 dB），差的 10 dB 全来自限值换挡 |

完整说明见 [`06-noise/README.md`](06-noise/README.md)。

### 课题 08　多姿态步态加速度特征采集与对比

用手机加速度计采平地走、快跑、上下楼梯、静止的竖直加速度，提炼能区分动作的阈值规则。

| 项 | 内容 |
|---|---|
| 目录 | [`08-gait/`](08-gait/) |
| 数据 | 46 段（本人 40 + 两位同学 6），保留 Phyphox 原始 CSV |
| 主结论 | **46 段全部判对**；但更该看的是 **冻结规则盲测 2/3** |
| 一句话 | 46/46 是拟合，2/3 才是泛化——所以两个数一起给 |

完整说明见 [`08-gait/README.md`](08-gait/README.md)。

## 目录约定

每个课题一个子目录，内部统一用这套结构：

```
06-noise/ 与 08-gait/
├── README.md              # 三分钟版结论 + 边界 + 怎么读
├── docs/                  # 方法说明、分析说明、局限
├── code/                  # 可执行脚本（包内可直接跑的部分已标注）
├── data/                  # 原始数据（csv / zip / 照片）
├── results/               # 中间结果（特征表、评估 JSON）
├── figs/                  # 图表
└── 证据包/                # 采集证明：谁、何时、在哪、用什么设备、怎么核验
```

`证据包/` 是为了回答一个具体问题：**凭什么相信这些数是真采的**。
里面放设备型号、采样设置、逐组时间戳、双源对照、以及一条能自己跑一遍的核验命令——
`06-noise/code/verify_raw.py` 会把 15 组的哈希重算一遍，输出「核验一致 15 组，不一致 0 组」。

---

## 两个课题共同的三个做法

1. **先写判据，再看数据。** 阈值从国标（GB 3096-2008）或实测空隙里来，不从"试到好看为止"里来。
2. **把不确定度算出来。** 06 给了 ±3 dB 的区间判定和翻转率；08 给了每条规则的余量表（最窄的一条只剩 0.02）。
3. **局限写在前头。** 两个课题的 README 第七节都是「已知失效场景」，不是等被问到才承认。
