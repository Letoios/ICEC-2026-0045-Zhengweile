# 课题 08　多姿态步态加速度特征采集与对比

用手机内置加速度计采集 **静止 / 平地走 / 跑步 / 上台阶 / 下台阶** 五种运动状态的竖直加速度波形，
提取**一组与个人幅度无关的无量纲特征**，归纳成 **六步判定规则**。

- 单人 16 段 + 手提 3 段 + 跨人 6 段 + 补采 9 段，共 **37 段实测**：**35 对 / 0 错**，且**没有一次拒答**
- **跨人 6 段（两位同学，同一台手机）：6 / 6 全对** —— 关键在判据从「单看自相关」换成了「自相关 + 正负差」
- **留一法 10 / 10、按人留出 10 / 10**（只用一个人定阈值去判另一个人，两个方向都成立，见 10.4）
- 幅度缩放到 0.5–2.0 倍（模拟不同体重、不同力度的人）：**8 / 8 全对**
- 走快走慢 ±15%（时间伸缩）：×0.85 与 ×0.92 各错 1 段，其余全对
- 叠加噪声 40 → 5 dB（最强时噪声与信号等强）：**8 / 8 全对**

> 课题要求是"4 种状态（含上下楼梯）"。这里把上下楼梯**拆成两类**单独建模，
> 因为两者的受力时序相反（见第三节），拆开后规则更稳，也更能说明阈值是怎么来的。

## 二、数据是怎么采的

| 项目 | 设置 |
|---|---|
| 采集工具 | Phyphox（手机传感器 App） |
| 导出内容 | Accelerometer + Gravity，各自带独立时间戳 |
| 采样率 | 加速度 480 Hz，重力 200 Hz（**两者不同，必须按时间插值对齐**） |
| 手机位置 | 手持正常摆臂，握持方式全程不变 |
| 单段时长 | 28–96 s，每类至少 20 个完整步态周期 |
| 设备 | OnePlus PLK110 |
| 采集日期 | 2026-10-24 / 10-25 / 10-26（上台阶三段跨三天） |

**为什么必须用 `Gravity.csv`，而不能"取三轴均值当重力"**：
手机会随手臂摆动，整段均值把摆动量也平均进去了，重力方向估偏、竖直分量被系统性低估。
同一段数据，用均值估重力算出的竖直 RMS 是 2.59，用真值重力插值算是 3.56，**差 37%**，足以让判定翻转。
这是本次实验最重要的一条方法教训。

**处理流程**：

```
Accelerometer(t, ax, ay, az) ──┐
                               ├─ 按时间列 np.interp 对齐 ─→ 单位重力矢量 ĝ(t)
Gravity(t, gx, gy, gz)       ──┘
        ↓
竖直分量 v(t) = a(t) · ĝ(t)
        ↓
去直流 v_dyn = v − 1 s 滑动均值          （滤掉重力基线，只留步态波动）
        ↓
无量纲化 z = v_dyn / std(v_dyn)          （只保留标准差 → 幅度信息全部丢掉）
        ↓
从 z 上提取形状特征 → 5 步判定
```

## 三、特征：为什么一定要"无量纲"

这是 v2 相对 v1 最关键的改动，也是**换人之后还能不能用**的分水岭。

一个人走路抖得有多厉害，取决于体重、身高、步幅、发力习惯、手机往兜里塞得多紧。
如果阈值写成"竖直 RMS > 4.5 就算下楼"，那换一个 90 斤的女生来，整套规则立刻失效。

所以 v2 把每一步都先除以自身的标准差 `z = v_dyn / σ`，之后**只从 z 上取形状特征**：

| 特征 | 算法（在 z 上） | 物理含义 | 与人的关系 |
|---|---|---|---|
| 竖直 RMS | `σ`（**唯一保留的绝对量**） | 振动强度 | 仅用于"静止/跑步"两个极端 |
| 步频 | 正峰数 / 时长 | 走得快慢 | 与人几乎无关 |
| 自相关强度 | 归一化自相关在 0.4–3 Hz 的最大值 | 周期规整度 | 与人无关 |
| 正−负 | `z>+1.5` 的时间占比 − `z<−1.5` 的时间占比 | 向上/向下谁占的时间长 | 与人无关 |
| **偏度** | `E[z³]` | 波形往哪边"甩" | 与人无关 |
| 波峰因数 | `max|z|` | 有没有尖峰 | 与人无关 |
| 峰度 | `E[z⁴]` | 尖峰的尖锐程度 | 与人无关 |

**为什么上下楼梯能用"偏度"分开**（v2 新增的判据）：

- **下台阶**：每步有一段接近自由落体，随后触地急刹，支撑力陡增，向上加速度冲出一个**窄而高**的正峰。
  波形长时间压在中位以下、偶尔向上甩很高 → **偏度为正**（实测 +0.51 / +0.44）。
- **上台阶**：蹬地是缓慢持续做功，正峰宽而缓；抬腿后支撑忽然撤除，下落段更明显。
  波形更接近对称 → **偏度接近 0 或略负**（实测 −0.15 / −0.13 / +0.10）。

这个量比"幅度"稳，因为它是**形状**，跟这个人跳得多高无关。

## 五、六步判定规则（其中 ④ 分两支）

按顺序判断，**先满足的那一条直接出结果**。顺序不能调：①是绝对量级，②是信息量门槛，先把两个极端和一个"没信息"的挡掉；
③④ 才是形状，只在中等强度的三类之间做区分。

| 步 | 条件 | 判定 | 标定依据 |
|---|---|---|---|
| ① | RMS < **1.5** 且 自相关 < **0.35** | 静止 | 静止 0.52 / 自相关 0.12；其余最小 RMS 2.92。**加自相关是为了防止"轻手轻脚上楼"被当成静止** |
| ② | RMS < **0.8** 且 RMS × 自相关 < **1.0** | 平地走（能量低到没有步态信息，按「静默移动」归类，不拒答） | 静止 0.06、手提慢走 0.73；其余最低上楼 b 1.63。**必须排在①之后**——静止段的乘积只有 0.06，先判信息量会把静止误归成平地走 |
| ③ | 步频 > **2.0** **且** RMS > **6.0**，或 RMS > **10** | 跑步 | 跑步 2.40 Hz / 19.05；其余最高 1.67 Hz / 4.75。步频单独不成立：快节奏下楼到过 2.26 Hz，但 RMS 只有 6.5 |
| ④ | 正−负 > **0.035** **且** 偏度 > **0.25** **且** RMS ≥ **1.5** | 下台阶（触地尖峰型） | 慢下楼最低 +0.060 / 偏度 +0.44；上楼最高 +0.010 / 偏度 +0.10。两个条件都留 0.02 以上余量 |
| ④b | RMS ≥ **6.0** **且** 1.5 ≤ 步频 < **1.9** **且** rms/步频 < **5.0** | 下台阶（快下楼型） | 快下楼 6.43 / 6.98；每步冲量 4.29 → 5.0 → 6.17。见 §10.8 与 §十一 |
| ⑤ | 自相关 + 正负差 + 0.2·max(0,偏度) ≥ **0.631** | 平地走 | 走路 11 段最低 0.666、上楼 9 段最高 0.596，取中点 0.6308（37 段上重算，未变：新样本 score 0.602，仍在阈值下方） |
| ⑥ | 以上都不满足 | 上台阶 | —— |

v1 只用"正−负 > 0.03"一个条件判下楼，三段上楼分别是 −0.031 / −0.021 / **+0.010**，
最接近的一段离阈值只剩 0.020 —— 一次采集就能翻车。**v2 加偏度做并联，相当于给这一步上了双保险。**

## 六、验证：不只是"8/8"

### 6.1 直接判定

`gait_classify.py` 在单人 10 段上运行：**10 / 10 全对**，没有拒答。

```
样本：04_stairs_up
  RMS 2.92｜步频 1.30 Hz｜自相关 0.58｜正−负 -0.021｜偏度 -0.13｜波峰因数 3.65
  判定：上台阶　（ac+diff+0.2·skew⁺ = 0.556 < 0.631（自相关 0.58，正−负 -0.021，偏度 -0.13））
```

### 6.2 扰动鲁棒性（针对「换人」做的量化）

"换一个人来走，会不会就认不出来了"——本质上是三个变量在变：**幅度**（体重/力度）、
**速度**（步频）、**噪声**（环境与手机质量）。把这三样逐一施加到 8 段数据上重新判定：

| 扰动 | 范围 | 结果 |
|---|---|---|
| 幅度缩放（模拟不同体重/力度的人） | ×0.5 → ×2.0 | **8 / 8 全对** |
| 时间伸缩（模拟走快/走慢的人） | ×0.85 → ×1.25 | ×0.85 / ×0.92 各错 1 段，其余全对 |
| 叠加白噪声 | 40 dB → 5 dB | **8 / 8 全对** |
| 叠加白噪声（极端） | 5 dB（噪声≈动作强度） | 2/8 —— 已超出物理可信范围 |

![扰动鲁棒性](figs/fig5_扰动鲁棒性.png)

幅度缩到一半、拉到两倍都不影响判定，**这正是"无量纲化"带来的**：
v1 的规则在幅度 ×0.5 时会把上台阶判成静止（RMS 掉到 1.46 < 1.5），v2 因为加了周期性守卫而幸免。

### 6.3 还没做到的

**以上所有数据都来自同一个人。**"换人"这件事，我只能证明规则**在结构上**对幅度、速度、噪声不敏感，
**不能**证明它对另一个人的走路习惯也成立。这是本次实验最大的缺口，答辩时应主动说明：

- 真正要验证，需要再找 **2–3 个人**，每人每类各录 1 段，用现有阈值直接判（不重新调参），看通过率；
- 如果个别人过不了，再决定是调阈值，还是把"偏度"换成更稳的形态量。

## 七、已知失效场景

1. **慢跑会被判成走路**。慢跑 RMS 可能低于 10、步频也低于 2.0，落进 ④ 的自相关判断。补一档"慢跑"样本可解。
2. **手臂不摆了就失效**（端握不动、放在包里）。本套阈值只在"手持摆臂"下标定过。
   若必须支持多位置，应改为对**三轴合成**建模，而不是只投竖直方向。
3. **静止时手抖、或手机放在震动的桌面上**，RMS 会抬高、自相关也会升高，可能被判成"上台阶"。此时应报"不确定"而不是硬判。
4. **5 dB 级噪声下规则崩溃**（见 6.2）。真实场景中噪声远低于此，但如果是地铁、工地旁，需先做人声/机械声滤除。
5. **早期 5 段数据不可与本批混用**：那批没有 `Gravity.csv`，重力靠均值估计，量纲与本文不一致。

## 八、下一步

- 补采 **2–3 个人的数据**，做真正的跨人验证（这是当前唯一能显著提升可信度的事）；

- 加入 **FFT 主频与二次谐波比**，慢跑与快走的差异比 RMS 更稳。

## 十、跨人验证：我自己找同学做的盲测（6 段全对）

### 10.1 为什么非要**别人的**数据不可

#### 一句话：自己测自己，证明不了任何事

前面 6.1 的 10/10，全部来自**同一个人、同一台手机、同一个放法**。这种数字有一个致命问题：
它可能是「规则记住了我走路的习惯」，而不是「规则认出了走路这个动作」。

这两种情况的区别，用一个人的数据永远分不出来。因为**只要样本都来自你，任何一条规则都能在事后调到你满意**——
这也是为什么「再录 10 段自己的」解决不了问题：新数据仍然带着同一双手的习惯，只会把阈值调得更贴合自己。

#### 单人数据的三个假象

这三个不是我推想的，都是这次实测里真的出现了的：

**假象一：阈值被一个人的幅度定位。**
竖直 RMS 是这套规则里唯一保留的绝对量。我自己的平地走 RMS 4.67，女同学只有 2.37 —— **差一倍**。
只用自己的数据，`RMS < 1.5 判静止`、`RMS > 6.0 判跑步` 这些门槛会理所当然地按我的幅度去卡；
换一个体重轻、走路轻的人，同样的门槛就可能整条错位。

**假象二：类间空隙是虚高的，一换人就塌。**
这是最硬的一个数字。用 `ac + diff` 这条联合判据，**只在本人的 10 段上算**：

| | 走路最低 | 上楼最高 | 空隙 |
|---|---|---|---|
| 只用自己的 10 段 | 0.5974 | 0.5562 | **0.041** |
| 补上两位同学后（28 段） | 0.5974 | 0.5872 | **0.010** |

空隙塌了 **4 倍**。因为两位同学的走路分数比我还低，上楼分数比我还高，两头一挤，中间那条缝就几乎没了。
**如果我只有自己的数据，我会以为这条规则很稳（0.041），实际上它只对一个人稳。**

**假象三：错误被一个人的分布盖住。**
那套只用 `ac ≥ 0.70` 的规则，在**我自己的 10 段上是 10 / 10，一个错都没有**。
可第一次拿别人的快节奏上楼（H）去测，它的 `ac` 是 **0.77**，照样越过 0.70，被判成「平地走」——
因为我的 10 段里压根没有「快节奏上楼」这种分布，规则没机会在这里出错。

#### 同学的数据买的到底是什么

不是"多 6 个样本"，而是三样用钱买不到的东西：

1. **别的幅度**——把阈值从"我的尺度"拉回"人的尺度"；
2. **别的持机习惯**——暴露了 `自相关` 测的其实是"手机摆得规不规律"，不是"走路"（详见 10.3）；
3. **一个只能用别人的数据发现的错误**——第一版 **3 / 6**，两位同学的走路全被误判成上台阶。

#### 所以这一步是怎么做的

- **由两位同学亲自走、亲自拿手机**，我只说「用你平常的方式走 / 上楼梯 / 下楼梯，各 30~60 秒」，**不告诉他们我在看什么**；
- **不指定步速、不纠正姿势**，保证是他们自然的动作；
- 采集完，我**先把 6 个文件改成 A–F 匿名、只留加速度和重力两列**，再判（脚本不读文件名），判完才揭晓；
- **同一台手机、同一款 App（OnePlus PLK110 + Phyphox「Acceleration with g」）**——差异只可能来自"人"，不会混进"设备"。

三条合起来，才叫「换人、匿名、同设备」。缺一条，这个证明就不成立。

#### 它值多少分，说白了

这段故事在答辩里能顶三句话：

> 「我先用自己的 10 段做到 10/10，但我知道那不算数——自己测自己，规则可能只是记住了我。
> 所以我找了两位同学，蒙上名字测了 6 段，**3 / 6**。
> 定位到原因之后再回来改规则，现在跨人 6 / 6，按人留出两个方向都是满分。」

**发现错误 > 没有错误。** 一个"一开始就全对"的规则，评委只会想"你是不是挑过数据"；
一个"错过、说清了为什么错、修好了"的规则，才是真做过实验的样子。

### 10.2 第一版为什么失败（这段不能删）

用当时那套「只看自相关」的规则（`ac ≥ 0.70` 判走路），这 6 段的结果是：

| 样本 | 真实动作 | 判定 | 自相关 | 结果 |
|---|---|---|---|---|
| A | 男同学·走路 | 上台阶 | 0.57 | ✗ |
| B | 女同学·走路 | 上台阶 | 0.64 | ✗ |
| C | 女同学·下楼 | 下台阶 | 0.68 | ✓ |
| D | 女同学·上楼 | 上台阶 | 0.35 | ✓ |
| E | 男同学·下楼 | 下台阶 | 0.69 | ✓ |
| F | 男同学·上楼 | 上台阶 | 0.52 | ✓ |

**3 / 6，两位同学的走路全被判成上台阶。**

### 10.3 根因：`自相关` 测的不是动作，是持机习惯

| 样本 | 类别 | 自相关 |
|---|---|---|
| 作者·手持正常走 | 走路 | **0.88** |
| 作者·手持快走 | 走路 | 0.77 |
| 作者·手持慢走 | 走路 | **0.56** |
| 男同学·走路 | 走路 | 0.57 |
| 女同学·走路 | 走路 | 0.64 |
| 作者·上楼 a / b / c | 上楼 | 0.48 / 0.58 / 0.53 |
| 女同学·上楼 | 上楼 | **0.35** |
| 男同学·上楼 | 上楼 | 0.52 |

**同一个人走路，自相关可以从 0.88 掉到 0.56**（正常走 → 慢走）；而两个同学的上楼落在 0.35–0.52。
两类的取值范围直接交错 —— 单靠这一个量，物理上就分不开。

它测的是「手机有没有跟着步子规律地摆动」：摆臂大、节奏稳 → 高；手贴身、步子碎 → 低。
这跟你在走路还是上楼，没有必然关系。

**反例说明**：`下台阶` 为什么 2/2 全对？因为它用的是 `正负差 + 偏度` ——
**触地瞬间的波形不对称**，那是物理量，谁走都一样。所以能跨人的判据和不能跨人的判据，差别在这里。

### 10.4 修法：叠「正负差」与「偏度正部」，`ac + diff + 0.2·skew⁺ ≥ 0.631`

单个特征都已经试穿（10 个特征里最好的单特征，训练集 1 错、留一法 3 错）。
把两个特征的**等权相加**穷举一遍，`自相关 + 正负差` 是唯一在 10 段走路/上楼样本上 **0 错**的组合。
这个判据不是一次定稿的，中间塌过一次：

**第一步（10 段）：只叠 `ac + diff`，空隙 0.040。**
走路最低 0.597、上楼最高 0.556，取中点 **0.577**。
两次按人留出：只用作者 6 段定阈值（0.5774）判两位同学 → 4/4；只用两位同学 4 段定阈值（0.5659）判作者 → 6/6。
两个阈值都落进同一个空隙，所以 0.577 不是凑的。

**第二步（补到 28 段，含几段快走快上楼）：空隙塌到 0.008。**
2026-11-02 新采的 9 段里有一段「快节奏上楼」（`data/more/up_new_f`，步频 1.45、自相关 0.58），
它的 `ac + diff = 0.588`；而最慢的那段走路（`data/more/walk_hand_slow`）是 0.596。
**中间只剩 0.008**，阈值挂在哪边都要丢一段。

**第三步（加偏度项）：空隙回到 0.070。**

| 类别 | 段数 | `ac + diff` | `ac + diff + 0.2·skew⁺` |
|---|---|---|---|
| 平地走 | 9 | 0.597 – 0.860 | **0.666 – 0.886** |
| 上台阶 | 8 | 0.367 – 0.587 | **0.403 – 0.596** |

最终阈值 **0.631**，正好是空隙 (0.5956, 0.6660) 的中点 0.6308，距两侧各 0.035。

偏度为什么能用：**走路脚跟着地是「先撞一下」，竖直加速度分布右偏；上楼是蹬起来的，没有那一下冲击，分布接近对称。**
所以这一项有物理解释，不是拟合出来的系数。权重 0.2 取在 0.15–0.30 的平台区上，不是峰值点。

三种检验（全部在 37 段上重算）：

| 检验 | 做法 | 结果 |
|---|---|---|
| 留一法 | 每次留 1 段，用其余 16 段重定阈值再判它 | **17 / 17** |
| 按人留出（正向） | 只用两位同学 4 段定阈值（0.613）→ 判本人 13 段 | **13 / 13** |
| 按人留出（反向） | 只用本人 13 段定阈值（0.659）→ 判两位同学 4 段 | **4 / 4** |

见 `figs/fig15_跨人可分性.png`：一条数轴，上排绿点是走路、下排蓝点是上楼，红线 0.631，灰带标出空隙 0.070。

### 10.5 顺带修掉的两个坑

- **下台阶加 `RMS ≥ 1.5`**：极慢走时 `正负差` 与 `偏度` 会偶然同时越界（作者慢走 diff 0.036、偏度 0.62），
  靠能量把它挡回去；
- **去掉「拒答」**：原版有一段 `0.50 ≤ ac < 0.70` 判「无法区分」，实测中它把两位同学的走路全吞了。
  现在**每一步都给类别**，没有「不知道」这个出口。

### 10.6 结果的用法与边界

- **能用的**：判「走路 / 上台阶 / 下台阶 / 跑步 / 静止」五类，37 段全对，跨人 6/6；
- **要提醒的**：留一法 9/10 意味着**每 10 个人里大约会错 1 个**；最近的一对只差 0.041，
  再遇到「极慢走」或「很轻的上楼」就可能翻线；
- **不能用的**：口袋自由晃动、端握不摆臂 —— 那时 `自相关` 会整体塌下来，这套阈值不成立。

答辩时这一节不必藏。比起「我的准确率 97%」，
「我自己找人做盲测，第一版只有 3/6，我定位到原因、换成联合判据，现在 34/34；补采那 9 段是 8/9 起步、修完才全对；最后 6 段专挑快的录，又逼出一条新分支」
更可信，也更像一个做过实验的人说的话。

### 10.6.1 第二轮盲测（2026-11-02，9 段新采）

补采了 P0 要求的三类数据，**先盲判再看文件名**，结果 **8 / 9**。

| 段 | 真值 | 判定 | 自定义分数 | 错因 |
|---|---|---|---|---|
| A | 下楼 | 下台阶 ✓ | — | 走 ④ 通道 |
| B | 上楼 | 上台阶 ✓ | 0.583 | — |
| C | 走路 | 平地走 ✓ | 0.882 | — |
| D | 下楼 | 下台阶 ✓ | — | 走 ④ 通道 |
| E | 下楼 | 下台阶 ✓ | — | 走 ④ 通道 |
| **F** | **上楼（快）** | **平地走 ✗** | **0.587** | 只差阈值 0.010，正落在预判的薄格子上 |
| G | 上楼 | 上台阶 ✓ | 0.530 | — |
| H | 走路 | 平地走 ✓ | 0.756 | — |
| I | 走路 | 平地走 ✓ | 0.849 | — |

这一段就是上一节预警过的「走路 vs 上楼空隙只有 0.010」的现场兑现：
F 段是**快节奏上楼**（步频 1.45、自相关 0.58），自相关被持机摆动撑高了，于是越线。

**修法见 10.4**：加 `0.2·max(0,偏度)`，空隙 0.010 → 0.070，改后 26 段全对（含今日 9 段）。

**但必须说清楚**：今日这 9 段参与了参数选择，所以它们的 9/9 **不是独立验证**。
真正能当证据的是下一批「没参与调参」的数据。

### 10.8 第三批：专挑「快」的录，逼出一条新分支（2026-11-03）

前两轮补采都是常规速度。这一批反过来，六段全部**故意加快**：快走 2 段、快下楼 2 段、快上楼 1 段，外加一段"没那么快的跑步"。结果 **4 对 2 错**，错的偏偏是两段快下楼。

**为什么错。** 判下台阶原来只看"形状"：

```
正−负 > 0.035  且  偏度 > 0.25
```

这两个量的物理来源都是**触地冲击**——脚落地那一下身体被地面顶住，波形出现一个窄而尖的正峰，分布因此右偏。慢走下楼时这个峰很清楚。可一旦下得快，腿部肌肉会主动缓冲，那一下被"吃"掉了：

| | 正−负 | 偏度 | RMS | 步频 |
|---|---|---|---|---|
| 慢下楼（7 段） | +0.060 ~ +0.071 | +0.44 ~ +0.51 | 4.46 – 5.81 | 1.43 – 1.72 |
| **快下楼 1** | **+0.035** | **+0.25** | **6.43** | 1.76 |
| **快下楼 2** | **−0.000** | **−0.18** | **6.98** | 1.63 |

快下楼 1 恰好卡在两条线上（`+0.035` 不满足"严格大于"、`+0.25` 同理），快下楼 2 则完全对称、**看起来和上楼一模一样**。两段都被兜底判成上台阶。

**修法：形状失效时退回幅度。** 加了 ④b：

```
RMS ≥ 6.0  且  步频 < 1.9  →  下台阶
```

道理还是物理的：下得越快，每步身体下落的速度越大、落地减速越猛，竖直方向的 RMS 就越高；上楼正好相反，身体是往上蹬的，起伏小。37 段实测的幅度分档：

| 类别 | RMS 范围 |
|---|---|
| 静止 | 0.49 – 0.52 |
| 平地走 | 1.18 – 4.67 |
| **上台阶** | **2.56 – 5.58** |
| **下台阶（慢）** | **4.46 – 5.81** |
| **下台阶（快）** | **6.43 – 6.98** |
| 跑步 | 13.93 – 19.05 |

**这条分支的余量只有 0.42**（快上楼 5.58 距 6.0）。它比 ④ 的两条形状判据都脆，是全套规则里第二薄的地方，写在这里而不是藏起来。真要保险，得再补几段"很用力地上楼"来把上界顶实。

**加完 ④b 之后：37 段 34 对 0 错**（这是当时的数字，后来被 §十一 改写），而且走路 / 上楼那条 0.070 的空隙**一个数都没动**（走路最低仍是 0.6660、上楼最高仍是 0.5956、中点仍是 0.6308）。

### 10.7 下一步：还缺什么

按「性价比 × 可行性」排序：

1. **加气压计（最强，手机自带）** —— 上楼时气压持续下降、走平路不变。这是**物理可分**的，
   不再依赖波形统计。Phyphox 自带 `Pressure` 实验，只需和加速度同时录。
2. **补更多人的数据**：现在走路 5 段、上楼 5 段，其中 3 段来自同一个人。再来 3~5 个人，
   留一法才可能真正收敛。
3. **换持机无关量**：竖直/水平能量比、步态周期内的双峰结构、步频的稳定性（CV）。
4. **多特征分类器**（逻辑回归 / 小决策树）代替手写阈值 —— 但需要 ≥10 人 × 3 状态的数据，否则照样过拟合。
5. **要求标注持机方式**（口袋 / 手持摆臂 / 端握），按方式分别标定阈值。

## 十一、又一个新样本打破了 ④b（2026-11-10）

录了一段「用力上楼」（一步跨两级、蹬得很实，32.0 s），拿它一测：

| | RMS | 步频 | 正−负 | 偏度 | 旧 ④b 判成 |
|---|---|---|---|---|---|
| 用力上楼 | **9.08** | 1.47 | +0.043 | +0.24 | **下台阶（错）** |

上一节末尾那句「余量只有 0.42」当场兑现了——`RMS 9.08 ≥ 6.0` 且 `步频 1.47 < 1.9`，两个条件都满足，于是被判成下台阶。④ 也差 0.01 没过（偏度 0.24 < 0.25）。

**为什么不把门槛从 6.0 抬到 9.5**：那样两段快下楼（6.43 / 6.98）就漏回去了，只是把错误换了个方向。

**为什么换成「每步冲量」**：`rms / cad` 的物理意思是「每一步的平均加速度均方 × 周期」，粗略就是**每步冲量**。

| | rms/cad |
|---|---|
| 上楼 8 段（普通） | 1.76 ~ 3.31 |
| **用力上楼** | **6.17** |
| 下台阶 7 段（普通） | 2.67 ~ 3.61 |
| 快下楼 2 段 | 3.66 / **4.29** |

道理是：快下楼冲击短、步频高，每步冲量反而**小**；用力上楼每步要抬高一整级，冲量**大**。

**改法**：④b 从两条变四条，新增 `T_FAST_DOWN_IMP = 5.0` 与 `T_FAST_DOWN_CAD_MIN = 1.5`：

```
rms ≥ 6.0  且  1.5 ≤ cad < 1.9  且  rms/cad < 5.0   →  下台阶（快下楼型）
```

**结果：37 段 35 对 0 错**（用力上楼被 ⑤ 接住，score 0.602 < 0.631）。

**仍然没闭合的地方**：冲量 4.29 → 5.0 → 6.17，两侧余量 0.71 / 1.17，但 **4.3~5.0 之间一个样本都没有**；上界只由这 1 段撑着。这是目前最该补的一段数据（再录 1~2 段「负重大步上楼」或「更快的下楼」都行）。见 `figs/fig17_每步冲量.png`。
