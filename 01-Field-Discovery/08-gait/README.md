# 课题 08　多姿态步态加速度特征采集与对比

用手机加速度计采平地走、快跑、上下楼梯、静止的竖直加速度，提炼能区分动作的阈值规则。

**完整报告在 [`docs/README.md`](docs/README.md)**（31 KB，含方法、特征全表、九条规则、验证、失效场景）。本页只放三个数和目录导航，方便先看结论。

---

## 三个数

| 数 | 含义 | 该不该信 |
|---|---|---|
| **46 / 46** | 46 段实测全部判对 | 这是**拟合**——46 段全参与过阈值标定，不能当命中率 |
| **2 / 3** | 冻结规则盲测（先判后看名字） | 这才是**泛化**，也是该拿去讲的数 |
| **6 / 6** | 两位同学的 6 段跨人全对 | 小样本，只证明「不是纯个人特征」，不证明「换谁都行」 |

一句话：**46/46 是拟合，0.5 是粗略估，2/3 才是泛化**，三个数一起给才诚实。

## 怎么验

```powershell
# 46 段逐段重判 + 与 features_all.csv 的 truth 列对数，最后一行给出「共 46 段，判对 46，判错 0」
python gait_classify.py --all --check
```

只判单段：`python gait_classify.py data\03_run`（给目录，或直接给 Accelerometer.csv 所在目录）。

包里还有 `fig_flow.py`（重画判定流程图，改阈值后重跑即可同步图）与 `_fig17.py`（重画每步冲量图）。

## 边界（写在前头）

- 46 段只覆盖 **3 个人、1 栋楼、运动鞋、没有过渡段**；跨人样本只有 6 段，且**已决定不再补人**，所以「换个人也准」不外推。
- 最窄的一条余量只剩 **0.02**（静止 vs 手提慢走的自相关），具体见 `docs/阈值规则.md` 余量表。
- 慢跑是后补的 ③b 分支救回来的；**步频 1.6–1.8 的快走 / 颠跑混合**仍无样本，这一段物理上连续、单段特征分不开。
