# 课题 08　动作判别阈值规则（精简版 · 一页卡）

> **适用条件只有一个：手持手机、手臂自然摆动。** 手持摆臂 15 段里判对 13 段（另 1 段是主动拒答），平均滑窗一致率 89.2%。
> 端握不动目前只有 1 段实测，**判错了**，因此不列入可用条件，只作为失效边界记录。
>
> 其余条件：Phyphox「Acceleration with g」，单段 ≥ 15 s、只含一个动作。

---

## 一、五个特征（全部无量纲，与个人幅度无关）

| 记号 | 含义 | 怎么算 | 物理意义 |
|---|---|---|---|
| `rms` | 竖直动态 RMS (m/s²) | 唯一保留**绝对量**的特征 | 抖得有多厉害 |
| `cad` | 步频 (Hz) | 归一化波形中每秒峰数 | 走/跑多快 |
| `ac` | 自相关强度 | 波形与自身延迟的相似度 | **波形有多重复** → 走路的身份证 |
| `diff` | 正峰% − 负谷% | 正向超 1.5σ 与负向超 1.5σ 的时间占比之差 | **受力对称性** → 上下楼的身份证 |
| `skew` | 偏度 E[z³] | 归一化波形的三阶矩 | **尖峰朝上还是朝下** |

`z = v_D / σ`，`v_D` 是竖直加速度去掉 1 s 滑动均值后的动态部分。

---

## 二、六步判定（自上而下，命中即停）

```
预处理：重力投影 → 去 1 s 均值 → 裁首 3 s / 尾 2 s
  │
① 信息量   rms × ac < 1.0            → 无法判定
  │ 否
② 静止     rms < 1.5  且  ac < 0.35  → 静止
  │ 否
③ 跑步     (cad > 2.0 且 rms > 6.0) 或 rms > 10   → 跑步
  │ 否
④ 下台阶   diff > +0.035  且  skew > +0.25        → 下台阶
  │ 否
⑤ 平地走   ac > 0.70                              → 平地走
  │ 否
⑥ 上台阶   （兜底）
```

---

## 三、阈值与余量（标定自 8 段实测数据）

| 阈值 | 值 | 上侧样本 | 下侧样本 | 余量 |
|---|---|---|---|---|
| `rms`（静止） | 1.5 | 上楼最低 2.92 | 静止 0.52 | 大 |
| `ac`（静止守卫） | 0.35 | 上楼最低 0.48 | 静止 0.12 | 大 |
| `cad`（跑步） | 2.0 | — | 上楼最高 1.45 | 0.55 |
| `rms`（跑步下限） | 6.0 | 跑步 19.05 | 下楼最高 4.90 | 1.1 ← 修 bug 用 |
| `diff`（下楼） | +0.035 | 下楼最低 +0.060 | 走路最高 +0.041 | **0.019（最薄）** |
| `skew`（下楼） | +0.25 | 下楼最低 +0.44 | 上楼最高 +0.10 | 0.15 / 0.19 |
| `ac`（走路） | 0.70 | 走路最低 0.72 | 上楼最高 0.58 | 0.12 / 0.14 |
| `rms×ac`（信息量） | 1.0 | 上楼最低 1.63 | 手提慢走 0.73 | 0.6 / 0.3 |

## 四、为什么这样排序

| 编排 | 理由 |
|---|---|
| 信息量放第 ① | 信号里没有步态就不要硬判，"无法判定"比判错诚实 |
| 静止、跑步放最前 | 唯一两个**绝对量**就能分开的极端类，不占用形状判据 |
| 下楼靠 `diff`+`skew` 双与门 | 单个判据余量只有 0.02，两个并联后错判概率大降 |
| 走路靠 `ac` | 走路是**最重复**的动作，自相关天然最高（0.72–0.89） |
| 上楼兜底 | 上楼幅度小、对称性介于两者之间，没有独占特征 → 只能当兜底 |

## 五、失效边界（必须写在报告里）

| 情形 | 表现 | 原因 | 证据强度 |
|---|---|---|---|
| **端握不动（不摆臂）** | `diff` 冲到 +0.041、`skew` +0.37，被判成下台阶 | 手臂不摆，手机只感到手的抖动，波形失去步态周期性 | **n = 1**（观察到失效，非统计证明） |
| **极慢速行走** | `skew` 冲到 +1.23、`ac` 掉到 0.63，被判成上台阶 | 冲击太弱，自相关与偏度都退化 | **n = 1**（同上） |
| 单段 < 10 s | 5 s 窗逐窗只有 72.5% | 4–5 s 只装 5–6 步，统计量还没长出来 | n = 12 段（充分） |
| 一段里混进 25 % 别的动作 | 降到约 82 % | 滑动窗口会跨过动作边界 | n = 239 窗（充分） |
| 只有 Linear Acceleration（无重力文件） | 只能分 3 类：静止 / 走路 / 跑步 | 上下楼的唯一区别在竖直方向的不对称性，没重力方向就投不出来 | 跨设备实测量（充分） |
| 峰值超过手机量程 | 波形削顶，`diff`/`skew` 失真 | 跑步峰值实测 8.42 g，已贴近 ±8 g 量程上限，建议调 ±16 g | 单段实测 |

> 说明：前两条各只有 1 段样本，报告中必须写明"观察到失效，样本量不足，未做统计验证"，不能写成"已证明失效"。

## 六、准确率（每个数字都带条件）

| 条件 | 结果 |
|---|---|
| 整段判定（训练集 8 段） | 8 / 8 |
| 12 s 滑窗逐窗（276 窗） | 92.0 % |
| 20 s 滑窗逐窗（239 窗） | 100 % |
| 幅度 ×0.5 – ×2.0 | 8/8 不变 |
| 时间伸缩 ×0.85 – ×1.25 | 8/8 不变 |
| 噪声 40 – 10 dB | 8/8 不变 |
| 噪声 5 dB（噪声＝信号） | 2/8（极端，不纳入适用范围） |
| 20 s 窗 + 3 次磕碰尖峰 | 100 % |
| 20 s 窗 + 停顿 2 s / 5 s | 98.7 % / 96.2 % |
| 20 s 窗 + 混入 25 % 别的动作 | 85.4 % |
| **未见过的文件盲测（12 段动作段）** | **下台阶 3/3、平地走 5/7、上台阶 1/2** |
