# photos/ —— 现场照片在哪

这个目录里原本放着 9 张现场照 + 1 条跑步现场视频，**现在移走了**。

## 为什么移走

这 10 个文件与仓库里 `08-gait/08课题运动原始文件现场/` 的文件**逐字节相同**（MD5 一致，见下表）。
同一份东西存两遍，clone 下来工作区要多占 14 MB，而且两边容易改不同步——所以只保留原件，这里不再复制。

| 文件 | MD5 与原件一致 | 原件位置 |
|---|---|---|
| `上台阶.jpg` / `上台阶_1.jpg` | ✅ | `../08课题运动原始文件现场/` |
| `下台阶.jpg` / `下楼.jpg` | ✅ | 同上 |
| `走路.jpg` / `走路记录.jpg` | ✅ | 同上 |
| `跑步.jpg` / `跑步现场.mp4` | ✅ | 同上 |
| `静止.jpg` / `静止1.jpg` | ✅ | 同上 |

核对命令（在 `08-gait/` 下执行，Windows PowerShell）：

```powershell
Get-ChildItem photos -File | Where-Object { $_.Name -ne 'README.md' } | Get-FileHash -Algorithm MD5
```

现在这条命令应该只输出空结果——因为文件都在 `08课题运动原始文件现场/` 里了。

## 为什么还留着这个目录

老师的目录规范里，阶段一要交「照片与 raw_data」。目录留着，是为了**以后补拍的照片有地方放**；
已有的这批属于「原始采样现场」，归在 `08课题运动原始文件现场/` 更准确——那里还同时放着同批的原始 zip 包。

## 原始现场里都有什么

```
08课题运动原始文件现场/
├─ 上台阶.jpg / 上台阶_1.jpg
├─ 下台阶.jpg / 下楼.jpg
├─ 走路.jpg / 走路记录.jpg
├─ 跑步.jpg / 跑步现场.mp4
├─ 静止.jpg / 静止1.jpg
├─ 上楼梯.zip / 下楼.zip / 走路记录 2026-10-24 17-56-11(3).zip
├─ 跑步 2026-10-24 18-04-02(1).zip / 静止 2026-10-24 18-00-40.zip
└─ ...
```

照片与 zip 是**同一次采集**的两部分：照片证明"人在现场、设备是这样拿的"，zip 是原始传感器数据。
