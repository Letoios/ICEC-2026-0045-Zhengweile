# 课题 06　校园昼夜声学噪声地图测绘

> 5 个点位 × 3 个时段 = **15 组**声学实测数据，全部来自手机 + Phyphox 现场采集。
> 结论：**13 组超标 / 2 组达标**（仅主干道在早、中两个时段达标，因其属 4a 类，限值 70 dB）。
> 在达标要求之外，另交付一套「声学超标自动提醒」的**光效逻辑**与**创新体系**（区间判定 / 制度性阶跃剥离 / 可信域地图）。

## 二、15 组结果一览

| 时段 | 图书馆 1类 | 食堂 2类 | 主干道 4a类 | 运动场 2类 | 实训室走廊 1类 |
|---|---|---|---|---|---|
| 早 昼间 | 61.4 **+6.4** | 62.5 **+2.5** | 63.5 −6.5 ✓ | 61.5 **+1.5** | 59.6 **+4.6** |
| 中 昼间 | 61.2 **+6.2** | 64.0 **+4.0** | 57.3 −12.7 ✓ | 60.8 **+0.8** | 60.5 **+5.5** |
| 晚 夜间 | 60.6 **+15.6** | 62.8 **+12.8** | 60.3 **+5.3** | 63.1 **+13.1** | 59.2 **+14.2** |

单位 dB(A)；数字为 Leq，加粗为超出量 Δ = Leq − 该点该时段限值（GB 3096-2008）。

**三个必须先看懂的现象**：

1. **夜间「全员超标」是制度性的，不是声学的**。夜间声级只比昼间低 3.1~1.6 dB，但限值降了 10 dB，于是超出量整体平移 8~10 dB。
2. **点与点之间的绝对差（≤ 4 dB）比仪器不确定度（±3 dB 未量化）大不了多少**，所以本报告不比较绝对声级，只比较「相对各自限值的偏移」。
3. **主干道是唯一达标的地方，不是因为安静，是因为尺子宽**。其 Leq 63.5 dB 比图书馆（61.4）还高。

## 四、这套东西的方法论要点

1. **判据用 Δ 不用绝对 dB**。五个点位分属 1/2/4a 三类，绝对限值从 55 到 70，直接比 dB 会把「宽尺子」误读成「安静」。
2. **判定改成三态**：确定超标 / 不确定 / 确定达标，用 ±3 dB 带宽把「贴线」的那几组诚实标出来，而不是假装都测准了。
3. **光效不追数值，追状态**。要回答的是「现在吵不吵」，不是「现在多少分贝」。
4. **诚实优先**。7 条异常（含「晚段是否应算夜间」这个会翻转结论的口径问题）全部登记在 `证据包/ANOMALIES.md`。

## 五、复现

所有指标可由 `data/` 里的原始序列重算：

```
Leq   = 10*log10(mean(10**(d/10)))        d 为约 9.2 Hz 的 dB 序列
Lmax  = max(d)
peak1s= 1 s 滑窗能量平均的最大值
L10/50/90 = 线性插值分位
Δ     = Leq − 该点位该时段 GB 3096 限值
```

核对用：`证据包/raw_output/extract_15组.txt`（纯文本，逐行对应 Excel 的 `01` 页）。

## 六、已知局限（答辩会问）

| 局限 | 说明 | 对应登记 |
|---|---|---|
| 绝对声级不可信 | 手机麦克风未接标准声级计；自动校准偏移跨度 22.35 dB | A-02 |
| 双源互差大 | 另一款 App 与 Phyphox 差 −5.6 ~ +15.4 dB，至少一套未校准 | A-03 |
| 机型不一致（已处理） | 初查晚图书馆一段为 PKG110；已定位为同学的重复件，改用本人 PLK110 原始文件夹 | A-01 |
| 晚段口径存疑 | 19:04—19:35 严格属昼间；换口径则 13 超标变 12 超标 | **A-06** |
| 单段时长有限 | 每点 82~125 s，反映局部而非全天；已复核样本数与时长一致、无丢帧 | A-04 |

**这些局限不是遮掩的对象，而是《创新体系》的起点**——正因为绝对量不可信，才把判据做成相对量 + 区间；正因为样本短，才把光效设计成看变化量而不是看绝对值。
