## 二、判定口径（先看这一段，否则下面的数会被误读）

GB 3096-2008 把一天切成两段：**昼间 6:00—22:00**、**夜间 22:00—6:00**，夜间限值比昼间低 10 dB。

15 组的实测时刻是：

- 早段 **07:56—08:21**
- 中段 **11:42—13:00**
- 晚段 **19:04—19:35**

**三批全部落在 06:00—22:00 之内，按标准都属于昼间。**

所以本报告的处理是：

1. **判定一律用昼间限值**（1 类 55、2 类 60、4a 类 70）。
2. 夜间限值不参与判定，只在 Excel 最后两列作**情景推演**：同一批声级，「假如它们发生在 22:00 之后」会是什么结果。
3. 这个选择不是取巧。校园的傍晚（19:00 前后）恰恰是人流与活动的高峰——学生回宿舍、食堂收尾、主干道通行；等到标准认定「夜间」开始的 22:00，校园里已经基本没人。**用夜间限值去判 19:00 的数据，保护的是一个并不存在的暴露人群。**

## 三、15 组结果一览

括号里的加粗数字是**按昼间限值的超出量 Δ**；斜杠后是**情景 Δ（若按夜间限值）**。

| 时段 | 图书馆 1类 | 食堂 2类 | 主干道 4a类 | 运动场 2类 | 实训室走廊 1类 |
|---|---|---|---|---|---|
| 早 | 61.4 **+6.4** / +16.4 | 62.5 **+2.5** / +12.5 | 63.5 −6.5 ✓ / +8.5 | 61.5 **+1.5** / +11.5 | 59.6 **+4.6** / +14.6 |
| 中 | 61.2 **+6.2** / +16.2 | 64.0 **+4.0** / +14.0 | 57.3 −12.7 ✓ / +2.3 | 60.8 **+0.8** / +10.8 | 60.5 **+5.5** / +15.5 |
| 晚 | 60.6 **+5.6** / +15.6 | 62.8 **+2.8** / +12.8 | 60.3 −9.7 ✓ / +5.3 | 63.1 **+3.1** / +13.1 | 59.2 **+4.2** / +14.2 |

单位 dB(A)；数字为 Leq。

**三个必须先看懂的现象**：

1. **同一批声级，换把尺子结论就翻转**。按昼间限值：12 超标 / 3 达标；按夜间限值：**15 组全部超标**。声级一个都没变，变的只是标准在这一刻用的是哪一档。这说明「超标」从来不是纯物理量，而是「声级 × 限值口径」的联合结论。
2. **傍晚并不比白天吵**。晚段 Leq 59.2~63.1，早段 61.4~62.5，中段 57.3~64.0——三个时段是同一个量级。校园噪声的峰不在深夜，在**傍晚的人流高峰**。
3. **主干道是唯一达标的地方，不是因为安静，是因为尺子宽**。其 Leq 63.5 dB 比图书馆（61.4）还高 2.1 dB，但 4a 类限值 70 dB 把它放行了。

## 五、这套东西的方法论要点

1. **判据用 Δ 不用绝对 dB**。五个点位分属 1/2/4a 三类，绝对限值从 55 到 70，直接比 dB 会把「宽尺子」误读成「安静」。
2. **口径必须写死并给出情景对照**。哪些时刻算昼间、哪些算夜间，标准说了算；但结论对口径有多敏感，必须自己算给读者看。
3. **判定改成三态**：确定超标 / 不确定 / 确定达标，用 ±3 dB 带宽把「贴线」的那几组诚实标出来，而不是假装都测准了。
4. **光效不追数值，追状态**。要回答的是「现在吵不吵」，不是「现在多少分贝」。
5. **诚实优先**。7 条异常（含口径、机型、校准偏移）全部登记在 `证据包/ANOMALIES.md`。

## 六、复现

所有指标可由 `data/` 里的原始序列重算：

```
Leq   = 10*log10(mean(10**(d/10)))        d 为约 9.2 Hz 的 dB 序列
Lmax  = max(d)
peak1s= 1 s 滑窗能量平均的最大值
L10/50/90 = 线性插值分位
Δ     = Leq − 该点位 昼间 限值（GB 3096-2008）
情景Δ = Leq − 该点位 夜间 限值（仅作对照，不参与判定）
```

核对用：`证据包/raw_output/extract_15组.txt`（纯文本，逐行对应 Excel 的 `01` 页）。

**不想看公式、只想验算**：`cd code && python recompute.py`。这个脚本只读本包 `data/`，
重算 15 组全部指标并与 `meta.txt` 对账，会在末尾给出最大偏差（当前 0.005 dB）。
只依赖 Python 标准库。全部脚本与运行顺序见 `code/README.md`。

## 七、已知局限（答辩会问）

| 局限 | 说明 | 对应登记 |
|---|---|---|
| 绝对声级不可信 | 手机麦克风未接标准声级计；自动校准偏移跨度 22.35 dB | A-02 |
| 双源不可比 | 另一款 App 与 Phyphox 差 −5.6 ~ +15.4 dB，且两者录制窗口重叠率 0%，只能当旁证 | A-03 |
| 机型不一致（已处理） | 初查晚图书馆一段为 PKG110；已定位为同学的重复件，改用本人 PLK110 原始文件夹 | A-01 |
| **无 22:00 后的实测（本课题主要局限）** | 晚段在 19:04—19:35，属昼间；夜间结论只能由情景推演得到，不是实测。补满 22:00—23:00 五组即可关闭本项 | **A-06** |
| 单段时长有限 | 每点 82~125 s，反映局部而非全天；已复核样本数与时长一致、无丢帧 | A-04 |
| 只测总声级 | 无频谱，只能答「多吵」，答不了「什么噪声」 | A-07 |

**这些局限不是遮掩的对象，而是《创新体系》的起点**——正因为绝对量不可信，才把判据做成相对量 + 区间；正因为口径能翻转结论，才把口径敏感性做成一个独立论点。
