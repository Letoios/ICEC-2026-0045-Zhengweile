## 2　指标怎么算

全部指标由 `noise06/extract.py` 从原始 `Amplitudes.csv` 重新计算，不依赖任何截图上的读数。

### 2.1　等效声级 Leq

把瞬时声级按能量平均，这是评价「一段时间的吵不吵」的标准口径：

```
Leq = 10 · lg( (1/N) · Σ 10^(Li/10) )
```

代码：`leq(vals) = 10*log10(mean(10**(d/10)))`。**注意是能量平均，不是算术平均** —— 算术平均会把偶发的 80 dB 尖峰抹平，Leq 不会。

### 2.2　峰值与 1 s 峰值

- **瞬时峰值 Lmax** = 整段样本的最大值。反映「最吵的那一瞬间」。
- **1 s 峰值** = 把 1 s 滑窗内的能量平均后取最大。比 Lmax 抗单点毛刺，比 Leq 更能反映短时冲击。

三个口径的值全部写进数据表，因为它们的用途不同：Leq 用于达标判定，Lmax / 1 s 峰值用于「冲击通道」告警。

### 2.3　统计百分位 L10 / L50 / L90

表示「有多长时间高于某个声级」。L10 = 有 10% 的时间超过它，通常当作「背景峰值」；L90 = 90% 的时间都超过它，可当作「背景底噪」。

### 2.4　判定与超出量

```
Δ = Leq − 该点位 · 该时段的适用限值
Δ > 0  →  超标      Δ ≤ 0  →  达标
```

限值取 **GB 3096-2008**：

| 点位 | 功能区 | 昼间 6:00—22:00 | 夜间 22:00—6:00 |
|---|---|---|---|
| 图书馆 | 1 类 | 55 | 45 |
| 实训室走廊 | 1 类 | 55 | 45 |
| 食堂 | 2 类 | 60 | 50 |
| 运动场 | 2 类 | 60 | 50 |
| 主干道 | 4a 类 | 70 | 55 |

### 3.2　三个必须说清楚的现象

**① 真正的问题不是「夜间超标」，而是「标准的时间分区与校园节律错配」。**
晚段实测时刻是 **19:04—19:35**，按 GB 3096 的默认时段仍属**昼间**。而傍晚 19:00 恰恰是校园人流与活动的高峰：学生回宿舍、食堂收尾、主干道通行。等到标准认为「夜间」开始、限值收紧 10 dB 的 22:00，校园里已经基本没人了。

换句话说，标准最松的那一档，正好盖住了校园最吵的两小时；标准最严的那一档，盖住的是校园最安静的三小时。这不是数据的错，也不是学校的问题，是**通用标准套在特定场景上的结构性偏差**——而它恰好是光效设计必须处理的东西（见《创新体系》创新二）。

为了把这件事量化，本报告在 Excel 最后两列给出了情景 Δ：按夜间限值，15 组会**全部超标**，其中 10 组超过 +12 dB。声级一个数字都没变。

**② 绝对声级的横向差异，小于仪器本身的偏差。**
15 组的 Leq 落在 **57.3 ~ 64.0 dB**，极差 6.7 dB。而同一测点用两套 App 记录的差值达 **−5.6 ~ +15.4 dB**（均值 +3.9）。也就是说，「哪个点位最吵」这类同一时段内的排序尚可信（差异集中、排序稳定），但把它当作可以互相校准的绝对值来比较，是站不住的。这一条直接支撑了第 4 节的区间判定。

**③ 主干道达标，是「限值效应」而不是「安静效应」。**
它的 Leq 63.5 dB 比图书馆的 61.4 dB 还高 2 dB，却因为 4a 类限值 70 而判达标。这类「按类别达标」的结果如果只报结论不报过程，很容易被问倒——所以数据表里限值与 Δ 都是并列给出的，并且额外给了夜间情景列，让读者能看到「同一个数字，换把尺子会怎么变」。

### 3.3　口径问题：晚段该用哪一档限值

GB 3096-2008 里昼间 / 夜间是两个**时段**而不是三个，默认划分为 **昼间 6:00—22:00、夜间 22:00—6:00**（具体时刻可由地方人民政府按当地作息划定）。

两种口径的结果差别：

| 口径 | 晚段评价依据 | 晚段结果 | 15 组合计 |
|---|---|---|---|
| **本报告采用** | 19:04—19:35 属昼间 → 昼间限值 55/60/70 | 4 超标 / 1 达标（主干道 −9.7 达标） | **12 超标 / 3 达标** |
| 对照（情景推演） | 若按校园作息视 19:00 起为夜间 → 夜间限值 45/50/55 | 5 组全超标 | 15 组全超标 |

**采用昼间口径的理由**：15 组的实测时刻全部落在 06:00—22:00 之间，按国标默认时段判定是本分；自行把「夜间」提前到 19:00 属于地方划定，需要依据（当地政府公告或学校作息文件），本课题拿不出这个依据。**宁可结论保守，不越权改标准。**

**但这个选择必须写明，因为它影响结论**：若改用夜间限值，晚段 5 组全部由「+2.8 ~ +5.6 dB 的轻度超标」变成「+12.8 ~ +15.6 dB 的严重超标」，主干道晚段也会由达标翻成超标。因此 Excel 与雷达图都保留了情景列，让这个分歧在报告里是**公开的**，而不是被藏起来。

**这也是《创新体系》创新二的由来**：夜间超标的成因里，有很大一块是「尺子换了一档」，而不是「声音大了一截」。谁掌握了这件事，谁就能解释为什么 22:00 一到整栋楼的灯会一起变红。

## 4　不确定度从哪来（这是本课题最容易被问倒的地方）

### 4.1　自动校准：每段一个偏移，跨度 22 dB

Phyphox 每段录制都会重新做一次自动校准，`Calibration.csv` 里记着这一段的偏移量：

| 段 | 偏移 dB | 段 | 偏移 dB |
|---|---|---|---|
| 早图书馆 | 96.79 | 中图书馆 | 102.83 |
| 早食堂 | 85.77 | 中食堂 | 82.64 |
| 早主干道 | 92.19 | 中主干道 | 80.49 |
| 早运动场 | 95.06 | 中运动场 | 98.51 |
| 早实训室走廊 | 93.54 | 中实训室走廊 | 87.32 |
| 晚图书馆 | 99.35 | 晚食堂 | 82.89 |
| 晚主干道 | 91.57 | 晚运动场 | 90.97 |
| 晚实训室走廊 | 100.84 | | |

**最低 80.49、最高 102.83，跨度 22.35 dB。** 这正是为什么最终 Leq 却只落在 57~64 dB 的窄带里：偏移量自动补偿了手机自动增益的差异。但代价是 —— 绝对声级依赖「开头几秒被当作静音」这个假设，而每段起始环境并不相同。

### 4.2　双源对照：两套 App 差 15 dB

每个文件夹里除了 Phyphox 的 zip，还有一个 `Transfer Dock_Text_*.txt`（另一款声级 App 的导出）。同一测点、同一时间段，两套读数：

| 测点 | Phyphox | 另一款 App | 差值 |
|---|---|---|---|
| 早实训走廊 | 59.59 | 65.23 | −5.6 |
| 早食堂 | 62.49 | 62.81 | −0.3 |
| 早路干 | 63.46 | 57.31 | +6.2 |
| 早操场 | 61.48 | 57.36 | +4.1 |
| 早图书馆 | 61.42 | 50.99 | +10.4 |
| 中图书馆 | 61.18 | 48.37 | +12.8 |
| 中实训室 | 60.49 | 59.43 | +1.1 |
| 中操场 | 60.79 | 51.83 | +9.0 |
| 中路干 | 57.34 | 60.38 | −3.0 |
| 中食堂 | 63.98 | 67.66 | −3.7 |
| 晚图书馆 | 60.58 | 51.54 | +9.0 |
| 晚实训室 | 59.23 | 43.80 | +15.4 |
| 晚操场 | 63.09 | 58.41 | +4.7 |
| 晚路干 | 60.34 | 59.93 | +0.4 |
| 晚食堂 | 62.75 | 64.63 | −1.9 |

**差值 −5.6 ~ +15.4 dB，均值 +3.9 dB，且正负都有、不集中。** 结论很明确：两套 App 至少有一套没有做声级校准。在没有标准声级计做基准的前提下，**不能声称任何一个绝对值是「真值」**。

### 4.3　因此采用 ±3 dB 作为保守偏差

把上面两条合起来，给一个保守的偏差带：**±3 dB**（比双源实测极差小，取的是「结论不翻转」的保守判断，理由见《创新体系》第 2 节）。据此把 15 组重新分为三档：

- **确定超标 8 组**：Δ − 3 > 0
- **确定达标 3 组**：Δ + 3 < 0（主干道早 −6.5、中 −12.7、晚 −9.7）
- **不确定 4 组**：中运动场 +0.8、早运动场 +1.5、早食堂 +2.5、晚食堂 +2.8 —— 这四组的 |Δ| 都小于 3 dB，换一台手机就可能翻转

**这个分类比「12 超标 3 达标」更有信息量**：它明确告诉你哪 11 个结论稳、哪 4 个结论脆。对一个要装在墙上、天天亮着的装置来说，这个区别是决定性的——落在灰带里的点位，灯不应该给确定性的红，而应该给「黄闪 + 建议延长采样」。

## 5　与雷达图的关系

雷达图画的是 **Δ** 而不是绝对 Leq，原因：五个点位分属 1 类 / 2 类 / 4a 类，绝对限值从 55 到 70 不等。如果画绝对声级，主干道永远在最外圈，会被误读成「最吵」。换成 Δ 之后五个方向共用一把尺子：**0 线就是限值线，越往外越超标**。

图上能看到：**三条曲线几乎贴在一起** —— 同一批点位，早、中、晚三个时段的 Δ 相差不到 3 dB。这和第 3.2 节①是同一件事的两种画法：校园噪声在一天里的起伏，远小于标准换挡带来的阶跃。

若把晚段的限值换成夜间限值再画一次（见 `fig3`），那圈会整体外扩 10 dB —— **外扩的是尺子，不是声音**。
