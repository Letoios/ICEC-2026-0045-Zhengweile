# 采集证明　验证说明

## 这份证明了什么

| 想证明的事 | 靠什么证明 | 能不能伪造 |
|---|---|---|
| 数据是**在那些时刻**采的 | `meta/time.csv` 的 START/PAUSE 系统时间（毫秒级，带 UTC+08:00） | 修改需要重新打包 zip，会让 SHA256 变化 |
| 数据**没被改过** | 每个 zip 的 SHA256，与 `采集证明.csv` 逐字符比对 | 改一个字节哈希就变 |
| 用的是**哪台设备** | `meta/device.csv` 的 deviceModel / version / build | 与 zip 绑定 |
| 同一点位有**第二个 App 佐证** | `Transfer Dock_Text_*.txt` 的毫秒时间戳与 dB 序列 | 时间戳由系统写入 |
| **现场确实去过** | 每个点位 3 张图：现场照（mmexport/IMG_）+ 手机截图（含 App 界面）+ 导出缩略图 | 照片含 EXIF 拍摄时间 |

## 怎么自己验一遍

```powershell
# ① 看证书表
Import-Csv "采集证明_设备时间与设备型号.csv" |
  Format-Table 编号,时段,监测点位,"设备型号","开始时刻(系统时间)","自动校准偏移(dB)","判定" -AutoSize

# ② 抽查一个 zip 的指纹
Get-FileHash "D:\分贝项目\早图书馆\声音振幅 2026-10-27 08-19-38.zip" -Algorithm SHA256

# ③ 打开这个 zip，看 meta/time.csv 与 meta/device.csv
Expand-Archive "D:\分贝项目\早图书馆\声音振幅 2026-10-27 08-19-38.zip" -DestinationPath "$env:TEMP\chk" -Force
Get-Content "$env:TEMP\chk\meta\time.csv"
Get-Content "$env:TEMP\chk\meta\device.csv"

# ④ 指标重算对账
Get-Content "raw_output\extract_15组.txt"
```

四步能对上，就说明「这批文件 = 表里这一行 = 这些指标」是同一件事。
