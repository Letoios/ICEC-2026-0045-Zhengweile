# 03 · AI 协作记录

这里放的是**关键节点的提问与排障过程**，不是全部对话的流水账。

## 为什么要有这个目录

这份档案要回答的不是「我用没用 AI」（用了，而且用得很重），而是三个更难的问题：

1. **AI 帮上忙的地方，我能不能说清楚它为什么帮上忙？**
2. **AI 说错的地方，我是怎么发现的？**
3. **如果没有 AI，这件事我能不能自己做？**

第三个问题没有标准答案，但前两个必须有证据。所以下面每一篇都按同一个格式写：

```
问题 → 我的提问 → AI 的回答 → 我做的验证 → 结论 / 落到哪个文件
```

其中「**我做的验证**」是核心。AI 给的每一个数字、每一条结论，最后都必须落到：
- 能复现的脚本，或
- 能对账的原始数据，或
- 官方文档 / 标准原文

没验证过的不写进报告 —— 这条规矩贯穿了整个项目，也贯穿了这份档案。

## 四个数字（脱敏后的使用强度）

- 整个项目跨越约 **20 天**、**约 200 轮**对话
- 其中**真正改变结论**的 AI 输出：约 **12 次**
- **AI 判断错误**、被我验证推翻的：**8 次**（全部记在 04 篇）
- **我主动否决** AI 建议的：**3 次**（也在 04 篇）

## 一点说明

这份档案里的「AI」指的是同一次会话中长期协作的助手。
它会犯错，也会在被指出后修正 —— 04 篇里那些案例，多数是**它自己发现并主动纠正**的，少数是我发现的。两种都记下来，因为真实的人机协作本来就是这样。
